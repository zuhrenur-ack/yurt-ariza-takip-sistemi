# Yurt Arıza Takip Sistemi (PHP & MySQL)

Bu proje, yurtlardaki manuel (defter usulü) arıza bildirim süreçlerini dijitalleştirmek için geliştirilmiştir.

## 🚀 Öne Çıkan Özellikler
- **Dinamik Dashboard:** Arızaların kategorilerine göre grafiksel analizi.
- **Güvenli Dosya Yükleme:** `uniqid()` ile çakışma riski olmayan fotoğraf yükleme.
- **Güvenlik:** SQL Injection saldırılarına karşı Prepared Statements (Hazırlanmış Sorgular) kullanımı.

## 🛠 Kullanılan Teknolojiler
- PHP & MySQL
- HTML5 & CSS3
